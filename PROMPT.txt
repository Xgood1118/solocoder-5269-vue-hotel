需求：Vue3 + Node.js 全栈酒店 PMS（Property Management System），房态 / 预订 / 入住 / 退房 / 发票 / 渠道管理。

背景：家里亲戚开了个民宿，10 间房，平时用 Excel + 微信处理预订很乱。我们想做一个轻量 PMS：房态图（房型 × 日期格子）、多渠道订单聚合（携程 / 美团 / 自营）、入住登记、退房结算、电子发票。技术栈 Vue3 SPA + Express + SQLite。

核心功能：
- 房型 / 房态：房型（标间 / 大床 / 套房）、物理房间、每晚房价（平日 / 周末 / 节假日不同）
- 预订：散客预订（直营）、渠道订单（携程 / 美团 / 飞猪推送订单）
- 渠道管理：渠道 API 接入（mock）、价格 / 库存同步（房型 + 房量 + 房价）
- 入住：身份证登记（mock 公安系统接口）、押金、房卡号
- 房态图：横轴日期（30 天滚动）、纵轴房号；不同颜色表示在售 / 已订 / 在住 / 脏房
- 退房：检查（mini bar 用量、物品损坏）、结算（房租 + 杂费 - 押金）
- 发票：电子发票（mock 税控接口），保存 PDF / 二维码
- 报表：入住率、ADR（平均房价）、RevPAR（每可用房收入）

涉及模块：
- `server/api/`：rooms、bookings、checkin、checkout、channels、reports
- `server/services/`：房价计算、库存管理、渠道适配器
- `server/scheduler/`：渠道同步 cron、对账
- `web/src/views/`：Dashboard、RoomMap、Bookings、Checkin、Reports、Channels
- `web/src/components/`：RoomGrid、Calendar、BookingForm、InvoicePreview
- `web/src/stores/`：Pinia stores

注意事项：
- 房态变更要"原子"：同一房型同一晚的库存只能被一个订单预订；用乐观锁 + 版本号
- 渠道订单要走"确认 → 入住 → 退房"完整状态机，不能只标个"已订"就完事
- 房价按"入住日"逐晚计算，每晚取对应日期的房价（平日 / 周末 / 节假日规则）
- 节假日日历要维护，每年提前导入；跨年预订跨多个节假日要按天切分计费
- 渠道库存同步要异步：用户下单 → 本地房态 - 1 → 异步推送给渠道（防超时）
- 渠道同步失败要重试 3 次 + 进死信队列，不能丢
- 入住登记要校验同一房间同一晚不能重复入住（防双开）
- 退房 mini bar 录入是体力活，要预设常用项（可乐 5 元 / 啤酒 10 元）+ 自定义添加
- 押金管理：入住时收 → 退房结算扣除后剩余退还；用流水账不用余额字段
- 发票生成：税率（6% 服务业）、抬头（个人 / 企业）、税号校验
- 渠道订单和直营订单要用同一套数据结构，加 `channel` 字段区分
- PMS 是高敏感数据，房态图只给内部员工看（密码 / 角色保护）
- 报表按月聚合：每月 1 号跑上月的入住率 / ADR / RevPAR，存历史表
- 节假日判定要兼顾：固定节日（国庆 10.1-10.7）+ 农历节日（春节 / 中秋，需农历转换库）
- 退房后房间变"脏房"，清洁阿姨标记"已清洁"后变"在售"
